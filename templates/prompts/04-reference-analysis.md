# Reproduire la qualité d'une référence

```markdown
Recherche comment reproduire le plus fidèlement possible <aspect> de la référence jointe, dans notre projet existant :
<composition, matières, reflets, profondeur…>, avec une méthode reproductible et compatible avec <contrainte :
animation, temps réel…>.

### 1. Analyser précisément la référence
Ouvre la référence et examine des agrandissements représentatifs (<zones>). Décompose : formes et distribution,
épaisseur et détails, surfaces, lumière et reflets, effets optiques, éclairage et compositing. Distingue les
caractéristiques visibles des hypothèses sur leur fabrication. Ne reproduis pas ses incohérences ni ses textes.
Compare des recadrages équivalents avec notre rendu ; montre les écarts dans une comparaison annotée.

### 2. Rechercher les méthodes et les experts pertinents
Toi-même, sans sous-agents, dans plusieurs langues : décompositions d'artistes spécialisés, documentation officielle,
dépôts et extensions réellement utiles, praticiens (forums spécialisés, Reddit). Vérifie démonstrations et contenu
technique ; un titre ou des étoiles ne suffisent pas. Pour chaque ressource : auteur, lien, apport précis, limites,
compatibilité, licence, maintenance. Si aucun skill n'apporte de bénéfice concret, dis-le. Réutilise les recherches
précédentes ; ne te limite pas à une liste de liens.

### 3. Définir la méthode adaptée à notre projet
Inspecte le projet avant de recommander. Compare les approches crédibles (<géométrie / textures / compositing…>) :
fidélité, contrôle, stabilité, coût. Recommande une approche principale et un repli ; explique comment obtenir chaque
caractéristique. Distingue ce qui demande de la géométrie de ce que font normales, matériaux ou compositing ; vérifie
les déformations sur une mire, puis sur le sujet.

### 4. Conclusion exploitable
Diagnostic illustré ; ressources directement applicables ; méthode et réglages à explorer avec leur effet attendu ;
écarts prioritaires ; protocole d'essai minimal (même cadrage, variantes contrôlées, côte à côte, court test animé).
Distingue documenté, déduit et testé. Le critère principal est une ressemblance visuelle convaincante.
<Pour cette étape : termine les essais et actualise la page d'aperçu, sans lancer la production complète.>
```
