# Glossaire

| Terme | Sens dans ce référentiel |
|---|---|
| **Personne qui dirige** | Celle qui commande, fixe l'intention, juge et valide ; son jugement visuel l'emporte |
| **Agent** | Claude Code : recherche, réalise, mesure, vérifie, documente ; décide seul du réversible |
| **Contrôle** | Vérification exécutée par l'agent, résultat cité |
| **Validation** | Décision explicite de la personne qui dirige après avoir vu le résultat |
| **Conditions finales** | Taille d'affichage, vitesse normale, traitement final, plateforme cible, œuvre entière, dernière version |
| **Critère essentiel** | Phrase du cadrage qui permet de juger chaque itération |
| **Échantillon** | Élément, extrait ou image représentatif sur lequel une méthode est mise au point avant d'être généralisée |
| **Extrait de validation** | Portion continue de la production finale, avec les réglages de livraison |
| **Diagnostic par extinction** | Neutraliser une cause possible à la fois jusqu'à ce que le défaut disparaisse |
| **Contre-essai** | Variante extrême (« tout traiter », « presque rien ») présentée pour révéler une préférence |
| **Modification nommée** | Changement d'essai appliqué par un banc à une copie de l'état de référence, sous un nom (`e1`, `e2`) |
| **Empreinte** | SHA-256 de toutes les dépendances d'une production ; protège la reprise contre le mélange de versions |
| **Sorties obsolètes** | Sorties d'un état dépassé, déplacées (jamais supprimées) dans `_stale/` |
| **Raccord (de boucle)** | Passage de la dernière image à la première ; invisible s'il est du même ordre qu'un écart consécutif |
| **Scintillement** | Pixel qui s'allume puis s'éteint d'une image à l'autre (accélération temporelle forte, aller-retour) |
| **Stabilisation temporelle** | Correction des seuls pics temporels par médiane de trois images recalées, sans flou spatial |
| **Profil de coût** | Mesure de la répartition du temps et comparaison de profils de réglages sur les mêmes unités |
| **Registre des consignes** | Liste des consignes durables, actives et remplacées, et des demandes avec leur état |
| **Journal** | Trace numérotée des essais et décisions d'une version ou d'un chantier ; une trace, pas une source de règles |
| **Chantier** | Travail long (plusieurs étapes ou sessions) avec sa branche et son journal |
| **D / T / H / O** | Statuts d'une affirmation de recherche : documenté, testé, hypothèse, observation |
| **[éprouvé] / [extrapolé] / [proposé]** | Niveaux de maturité d'une pratique dans ce référentiel |
| **Pré-compensation Apple** | Correction de gamma d'un flux vidéo destiné à la pile vidéo d'Apple |
| **2,5D** | Animation d'une image par calques projetés sur une géométrie légère, sans reconstruction 3D complète |
