# Guides de domaine

Méthodes concrètes, par technique. Chaque guide décrit des **procédures et des points de départ**, jamais des réglages
à recopier : les valeurs d'un projet se mesurent sur ce projet.

| Domaine | Guide |
|---|---|
| Rendu 3D précalculé : architecture reproductible, banc d'essai, diagnostic, matériaux transparents, scintillement, coût, boucle | [`offline-3d-rendering.md`](offline-3d-rendering.md) |
| Animation 2,5D d'un sujet à partir d'une image unique | [`2-5d-animation.md`](2-5d-animation.md) |
| Vidéo d'arrière-plan pour le web : exports, couleur, budgets, intégration, tests | [`web-background-video.md`](web-background-video.md) |
| Application web : test d'abord, couches, garde-fous, CI, Git | [`web-applications.md`](web-applications.md) |
| Modèles d'IA locaux et ressources tierces : provenance, licences, droits | [`ai-models-and-assets.md`](ai-models-and-assets.md) |

Pour un domaine absent, partir de [l'adaptation du workflow](../workflow/adapting.md), puis créer le guide après le
premier projet ([`CONTRIBUTING.md`](../../CONTRIBUTING.md)).
