# Method decisions (ADR)

A structural decision about **the way of working** gets a file `NNNN-title.md`
([template](../../templates/decision-record.md)). An accepted decision is challenged only by a new decision that
replaces it and says so. Project-specific decisions (technical or aesthetic choices) stay in that project.

| # | Decision | Status |
|---|---|---|
| [0001](0001-versioned-playbook.md) | A single, versioned method repository, separate from projects | accepted |
| [0002](0002-method-separate-from-aesthetics.md) | Keep the method separate from aesthetic choices | accepted |
| [0003](0003-no-subagents.md) | Research and work done by the agent itself, without sub-agents (default) | accepted |
| [0004](0004-preserve-the-source.md) | Preserve the source artwork; AI estimates, it does not regenerate | accepted |
| [0005](0005-final-conditions-over-metrics.md) | Judgement in final conditions comes first; measurements complement it | accepted |
| [0006](0006-fingerprinted-resumable-production.md) | Every long production is resumable and protected by a fingerprint | accepted |
| [0007](0007-no-project-content.md) | The playbook contains no project work or deliverable | accepted |
| [0008](0008-open-source-release.md) | Open-source release: explicit name, English, MIT licence, plugin | accepted |
