# Décisions de méthode (ADR)

Une décision structurante sur **la manière de travailler** fait l'objet d'un fichier `NNNN-title.md`
([modèle](../../templates/decision-record.md)). Une décision acceptée ne se remet en cause que par une nouvelle
décision qui la remplace et l'indique. Les décisions propres à un projet (choix techniques ou esthétiques) restent dans
ce projet.

| # | Décision | Statut |
|---|---|---|
| [0001](0001-versioned-playbook.md) | Un référentiel de méthode unique, versionné, séparé des projets | acceptée |
| [0002](0002-method-separate-from-aesthetics.md) | Séparer la méthode des choix esthétiques | acceptée |
| [0003](0003-no-subagents.md) | Recherches et travaux menés par l'agent lui-même, sans sous-agents | acceptée |
| [0004](0004-preserve-the-source.md) | Préserver l'œuvre source ; l'IA estime, elle ne régénère pas | acceptée |
| [0005](0005-final-conditions-over-metrics.md) | Le jugement dans les conditions finales prime ; les mesures complètent | acceptée |
| [0006](0006-fingerprinted-resumable-production.md) | Toute production longue est reprenable et protégée par une empreinte | acceptée |
| [0007](0007-no-project-content.md) | Le référentiel ne contient aucun travail ni livrable de projet | acceptée |
