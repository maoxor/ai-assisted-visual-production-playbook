# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good faith, welcome newcomers, and focus criticism on ideas and work,
never on people. Harassment, discriminatory language, personal attacks and the publication of other people's private
information are not tolerated.

## Scope

The code applies in every project space (issues, pull requests, discussions, reviews) and when someone represents the
project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub's private vulnerability reporting form
(**Security** tab → **Report a vulnerability**, mentioning "code of conduct" in the title), or by using GitHub's
**Report content** feature on the comment concerned. Reports are handled confidentially. Maintainers may remove, edit
or reject contributions that do not follow this code, and may temporarily or permanently ban a contributor, following
the enforcement guidelines of the Contributor Covenant.
